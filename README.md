# KiCad-PCB-to-CNC-G-Code-Exporter
A high-precision KiCad Action Plugin that exports your PCB directly to CNC G-code for copper isolation, full excess copper removal ("Leave Only Lines"), multi-pass custom spacing in `mm`, drilling (including oblong slots), and board cutout with holding tabs - complete with an Interactive Live 2D Preview and One-Click Mode Presets.
